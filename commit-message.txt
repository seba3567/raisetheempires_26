chore: the dead code in the battle engine, and a test that lies

The engine carried three blocks of code that had been commented out for
years -- two of them a second and a third version of a function that is
live a few lines below, and one that said "unused?" above it. They are
gone, and the note about the coins of a kill is now a note that says what
it is: the coins are proportional to the damage, so a kill pays more than
a hit, and the game's own table only says what the experience and the
energy are.

The bomber run test was asserting an exact balance after a bomb landed on
a crate -- and the crate is picked at random, and one of the five pays
empire points back. It failed one time in twenty, in whichever run drew
that crate. It now says what it means: the cost plus whatever the crate
gave.

And the admin commands are written down, all of them, with the reason
the first one reads the password from the environment instead of the
command line.
